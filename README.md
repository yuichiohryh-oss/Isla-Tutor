# Isla Tutor

Puerto Rico 型の役職選択ゲームを、NPC を相手に一人で練習できる非公式の Web アプリです。

**[ブラウザで遊ぶ](https://yuichiohryh-oss.github.io/Isla-Tutor/)**

## 遊び方

上のリンクを開くか、`index.html` を Edge または Chrome で開いてください。インストールやアカウント登録は不要です。ゲームの途中経過はブラウザのローカルストレージに自動保存され、同じブラウザで再開できます。ブラウザのサイトデータを消すと保存内容も失われます。

初めて遊ぶ場合は設定画面の「はじめて遊ぶ・チュートリアル」を選んでください。実際の画面で役職、農園、建物、入植者、商品、商館、船を操作しながら基本サイクルを覚えられます。「説明」ではカードのボタン、「操作してください」では黄色く強調されたゲーム画面を操作します。基本ゲーム・拡張なしを使う独立した教材モードです。教材中は通常ゲームの保存データを上書きしません。通常の保存データがある場合、教材終了後は前回のゲームへ戻れます。

## 収録内容

- 2～4人戦（人間1人、残りはNPC）
- 初級・中級・上級NPC
- 基本建物を使うゲーム（新建物拡張は準備中）
- 建物売り場で各建物の残り棟数を常時表示
- 人数別準備、役職、商品、生産、売却、出荷、建築、終了・大型建物得点
- バランス調整ルール
- NPCの役職評価と初心者向けコーチ表示

セーブ形式は v2 です。旧試作版の保存データとは互換性がありません。

## 開発・テスト

HTML、CSS、JavaScript のみで動作します。ビルドやパッケージのインストールは不要です。ゲームエンジンのテストには Node.js を使用します。

```sh
node tests/engine.test.js
node tests/tutorial.test.js
node tests/tutorial-dom.test.js
node tests/app.test.js
```
